## Current limitations

- Every dispatch serializes the complete model and complete VNode as JSON.
- The host repeats attribute writes and event-listener replacement for unchanged
  attributes.
- The model exists simultaneously as host JSON and transient Wasm values.
- Compatibility `oninput`, HTTP, navigation, port, secret, and compartment
  adapters identify message variants by string; the RFC-0107 Program path uses
  typed event decoders and typed completion callbacks.
- Routes, forms, accessibility primitives, CSS, classes, URLs, and template
  sink categories have dedicated public types. The complete maintained widget
  set and browser accessibility matrix remain later release work.
- Static `web() -> glamour.Site` builds own deterministic route discovery,
  escaped document rendering, progressive action and critical-resource graphs,
  content-addressed typed public assets, static artifact emission, and
  zero-runtime auditing. Interactive output atomically publishes authenticated
  content-named Wasm, rewritten pages, closed manifests, content-addressed
  runtime modules, and executable headers after a second island-aware audit.
- The optimized protocol carries only authenticated operations and scalar
  payloads. The compatibility JSON host still carries complete model and VNode
  values during its migration window.
- Browser behavior has strong dependency-free host tests and a pinned local
  Chromium, Firefox, and WebKit acceptance matrix. Public release-channel CI
  evidence and broader maintained-widget coverage remain required for 1.0.
- The generated starter uses `Program`, `Interactive`, and typed static `Site`.
  Its route, resumable island, executable adapter, event registry, and manifests
  are compiler-generated; it contains no source-authored browser protocol or
  whole-page mount root. Omitted `web.delivery` also selects this static path.
- Development snapshot format 1 covers capability-free scalar model fields.
  Aggregate public models use tracing-only format 0, expose exact redacted
  per-field structural change bits, omit migration exports, and reload until a
  deterministic checked aggregate serializer is implemented.
