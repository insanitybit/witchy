## 2. Mechanics that cost time when unknown

- **Never let cargo sit inside a tool call.** A cold build is 15-25 minutes;
  the tool timeout is 10. Run cargo through `scripts/rfc0165-dev/*.sh`
  (background + status file) and poll. Remove the status file in the
  foreground *before* launching, or a waiter reads the previous run's status
  (this bit twice).
- **Target dirs.** The slices used `/private/tmp/witchy-rfc0165-inner` with
  `CARGO_BUILD_RUSTC_WRAPPER=""`. The `witchy` on PATH is the release binary
  from the main checkout; probe with `$CARGO_TARGET_DIR/debug/witchy`.
- **The merge-queue journal lives in the main checkout**
  (`/Users/cobrien/workspace/witchy/state/merge-queue/journal.jsonl`), not in
  the worktree. A coordinator (`merge-queue.sh run`, pid 38402 at handoff) is
  alive and gates whatever is submitted; a gate takes 5-10 minutes. Submit the
  branch tip; the queue gates the SHA at submission, so a later commit needs a
  fresh submit. `fix/rfc0163-host-env-boundary` sits in the queue in conflict
  state; it is not ours.
- **Probing.** `witchy parity <file>` runs interpreter, admitted Wasm, and
  oracle; `WITCHY_CANONICAL_LOWER_DEBUG=1 witchy check <file>` dumps the lowered
  IR (now also prints the canonical scope). A probe that imports std must run
  from the worktree root. Under dev grants the compiled leg's `Dir` root is
  the working directory, so a probe that writes writes into the checkout.
- **Harness vs CLI.** Launch tests go through `resolve_std_only_checked`,
  which is stricter about method receivers: a receiver bound by `match` or a
  generic return needs `let x: Type = …`, and `.to_string()` on `Bytes`
  resolves only as `bytes.to_string(x)` there. `to_upper` is ASCII-only.
- **Subagent pattern that worked** (used for slice 42): freeze a contract
  file first (names, wasm shapes, roles, authorities, public API names), seed
  the shared enum/stub commit so every track compiles, then spawn each track
  with `isolation: worktree`, its own target dir, and an explicit file
  boundary; integrate by `git cherry-pick` of their commits; then run one
  bounded adversarial reviewer (read-only, with the prebuilt binary and probe
  programs) on the whole diff. Reviews found real defects every time: a
  closure code slot loadable before store, a `with_capacity` divergence, the
  oracle following symlinks. Skip the review only for docs.
- **Untracked review probes** go in the session scratchpad, never the repo;
  one reviewer created a symlink in the checkout and cleaned it up, verify
  `git status` after any review.

## 3. Lessons about the code (each of these cost a build cycle or more)

- **Layout ids are content hashes of descriptor bytes that embed child ids.**
  A self-referential layout is impossible; that is why recursive types need
  an opaque nominal pointee resolved through a side table (plan note).
- **The checker bounds a raw-byte element write by the buffer's capacity
  lane and a read by its count lane.** A growing kernel guards stores against
  the capacity id it allocated (`push_byte_store`), not the count it will
  publish. Count and capacity must be distinct value ids on every loop header
  edge; a fresh value aliases them (`split_lanes`).
- **Block parameters drop header facts.** Routing a `Size` through a join
  block after a host call lost the object's count/capacity facts
  (`InvalidExtent`); publish under a guard instead of a min-join.
- **`canonical_scope` must not be cached by a weak fingerprint.** It was
  keyed on function names plus statement counts and served a stale scope to
  the next same-shaped program on the thread (a std function reached only by
  the second program became a `MissingBinding`). Each pass now takes the set
  once; keep it that way.
- **Some public std names are intrinsic aliases** (`bytes.at` → `__bytes_at`):
  the scope excludes the wrapper and the lowering must dispatch the alias
  itself. Check `intrinsics::OPERATION_ALIASES` and `lookup`'s
  `private_callers` fallback before assuming a std function is in scope.
- **Capability rights are type arguments** (`Dir[Read]`). Every place that
  matches `Named(name, arguments) if arguments.is_empty()` misses them; the
  ABI encodes rights by name, sorted and deduplicated.
- **The frozen host's staged `pending` protocol is not admissible** on the
  canonical route (host state across calls, unbounded fill). The pattern that
  is: stateless bounded imports, `(ptr, capacity)` write slices, the guest
  asks with an empty buffer for the length, allocates exactly, asks again,
  and publishes the second answer under its own capacity guard.
- **The oracle must be no weaker than the host.** Its filesystem fallback
  now refuses links, non-files, non-UTF-8 reads, missing subtrees, and more
  `Dir` parameters than granted (`OracleFixture::dir_grants`). Every new host
  operation needs the same discipline on both legs and a probe that asserts
  the *abort* agrees, not only the happy path.
- **Abort diagnostics differ by design** (interpreter message vs Wasm trap);
  `parity` reports it as a diagnostic divergence. That is the known open
  point, not a bug in your slice; a value divergence or an oracle running
  where the backend refused is.
- **Fixtures in one test thread share nothing but the thread**; anything
  thread-local in the pipeline is a hazard (the scope cache was one).
- **The interpreter mints every `Dir` parameter of `main` at the working
  directory under dev grants; both compiled routes refuse a second ungranted
  `Dir`.** Pre-existing; recorded in the census, not fixed.

## 4. How I would finish the goal

The goal (as phrased for `/goal`): every example that does not use tasks,
Net, regex, or `opt_mode` checks and agrees on all three legs, delivered in
gated slices with launch tests, reviews, and docs, and a full green run on
master with the deferred list at its final size.

**Order of families, by unlock per unit of risk:**

1. **Recursive nominal types** (about ten examples). Follow
   `rfcs/0165-notes/recursive-types-plan.md`. Freeze two decisions before any
   code: `LayoutKind::OpaqueNominal { key }` plus interner `nominal_bindings`
   (carried as a bundle section), and `PointerSlot::OwnedNullable` (an
   unselected slot is null, never a fresh allocation). Then three parallel
   tracks against that contract: (a) wir layout/bundle/checker chase of the
   binding; (b) wir backend: one emitted `$drop_<layout>` Wasm function per
   pointer-bearing layout replacing the depth-unrolled destructor, plus the
   oracle's release as a work-list; (c) types/lowering: cycle-tolerant
   `field_type_ok`, `push_empty_value` storing null, layout projection.
   Slice A targets `examples/bst` on all three legs; B adds `Option(Tree)`,
   `List(Tree)`, tuples (calc, eval); C keys generic instances by
   `aggregate_key` (generic_stack) and then `json.Json`, which opens six
   more examples. Record deep-tree depth (backend trap, oracle no trap) as an
   obligation in the ledger rather than claim agreement.
2. **Command-line `args`.** Admission derives the entry from `main`'s closed
   callable ABI, so a synthesized wrapper cannot be the entry. The right
   shape is an admission-level *launch input*: the entry's `List(String)`
   parameter is recognized as `CanonicalEntryInput::Args`, the lowered entry
   drops it from its canonical signature and builds it in its prologue from a
   pure-infrastructure `args_into(out Write Slice) -> Size` import (NUL-joined
   argv, class `LaunchInput`, which `authenticated_prelude_import` must learn
   to accept), and the oracle fixture gains `arguments`. Touches
   `canonical_abi`/witness, `canonical_wasmir::derive_entry`, the runtime's
   `call_canonical_entry`, and the lowering; review it like a capability.
3. **Encoding kernels** (`encoding.*` intrinsics: hex/base64 encode and decode,
   ten intrinsics) as guest-side byte kernels over the `Bytes` layout, the
   same shape as slice 41. Adjudicate against Rust's `hex`/`base64` in the
   launch test the way `to_string` is adjudicated against `from_utf8_lossy`.
4. **The typeck gap** behind `generators`/`pascal` ("missing checked
   expression type" for an `if`): fix it in the typed path, then see what
   those examples refuse next.
5. Then sweep the census. Prune `scripts/rfc0165-deferred-tests.txt` as
   families are admitted (the typed-errors Bytes test was the first to leave;
   run the entry, and if it passes remove the line), and finish with a full
   `nextest --workspace --features witchy-wir/native` run on master with the
   untracked optimization-execution test moved aside.

**Working rules that kept velocity:** batch a slice's edits before a build;
probe with `parity` before writing the launch test; write the census entry and
the ledger delta in the same commit as the code (numbers re-derived by the
census script, never copied); submit, then start the next slice while the gate
runs, and have the reviewer read the *landed* diff so their findings become a
small follow-up commit rather than a rebase. Keep every refusal loud and
fail-closed; when a reviewer or a probe shows the oracle answering where the
host refuses, that is the bug to fix first.

**What not to do:** do not re-add per-program fallbacks or the frozen
encoder to satisfy a parity test; do not bring back a scope cache; do not
model rights or grants in the oracle beyond what the runtime enforces; do not
touch the four excluded families without their own RFC-level design (a
scheduler, sockets, a regex engine, the withdrawn `unique` surface).
