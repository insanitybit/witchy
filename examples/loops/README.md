# loops

`for x in list` binds each element of a list in turn. Combined with a mutable
`var`, it accumulates: this program sums a list of ints and joins a list of
words into a line.

**Shows:** `for ... in` over a list, mutable `var`, string interpolation, and
the `Console` capability.

## Run

```sh
witchy run                                # from this directory
witchy examples/loops/src/loops.witchy    # or by file, from the repo root
```
