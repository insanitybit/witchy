# floats

Float math from the bundled `math` module: `sqrt` (a builtin, since it can't be
written in witchy) plus the `Float` helpers `float_abs`, `float_max`, and
`float_clamp`. Only `main` touches the `Console`, to print each result.

**Shows:** the `math` module, `Float` arithmetic, and string interpolation.

## Run

```sh
witchy run                                  # from this directory
witchy examples/floats/src/floats.witchy    # or by file, from the repo root
```
